# Kishun Sharma Law Chambers Website

This is a responsive advocate-chamber website served with Python's standard library - no packages required.

## Run locally

The easiest option is to double-click [start_site.bat](start_site.bat). It starts the Python server and opens the website at `http://127.0.0.1:8000`.

Or run it manually:

```powershell
cd C:\codex\Doubts\advocate_site
python app.py
```

Then open `http://127.0.0.1:8000` in a browser.

To make the contact form send real requests, connect it to an email, CRM, or database service from the form submit handler.
